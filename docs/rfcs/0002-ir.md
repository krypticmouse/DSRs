# RFC 0002: The Intermediate Representation

**Status:** proposed · **Date:** 2026-08-14 · **Branch:** `v1-revamp` · **Depends on:** RFC 0001 (trace format), vision report §4.1/§5.1–5.3 · **Blocks:** structure optimization, `include_program!`, `dsrs serve`, Python/TS frontends · **Amended by:** RFC 0003 (Rust `#[module]` frontend: builder demoted to internal lowering target; `HoleImpl::Host`; bool `Route` discriminants; `Loop.init`; interpreter replay intercepts + hole `request_hash` preimage)

---

## 0. Summary

The IR is a **closed typed graph** over value-level signatures, with every mutable thing a named, addressable parameter, and one text form that LLMs generate under a constrained grammar.

Decisions, in one screen:

- **`SignatureDef` is an owned value** (strings, no `Sym` coupling, no macros required). The static lane keeps `#[derive(Signature)]` + monomorphized `Predict<S>`; `SignatureDef::of::<S>()` bridges. The four leaked `TypeId` caches collapse to **one** static-lane cache (bounded, deliberate); loaded programs own their signature arenas and leak nothing.
- **Type system = `typesys::FieldType` unchanged**, plus serde derives. What the macro rejects, the loader rejects — same closed subset both lanes.
- **`Program`** = `PrimaryMap` arenas (cranelift-entity), closed `Node` enum: `Predict`, `AgentLoop`, `Seq`, `ForkJoin`, `Route`, `Retry`, `Refine`, `Loop` (bounded), `Hole`. Predict has **no tools**; tool use is `AgentLoop` (collapses 3 tool paths → 1). `cot` is surface sugar (augmented signature), not a node kind — AFlow's result (small operator vocabulary makes search tractable) is why the enum stays this small.
- **Dataflow is field-level.** Nodes bind input fields to ports (`$.field`, `node.field`, loop-carried, literal). Values are `serde_json::Value` maps at the interpreter boundary.
- **`ParamSlot`** kinds: `Instruction | Demos | ToolDesc | ModelRef | ContextPolicy | Code`. `ParamPath` (string, serde boundary) → `ParamId(u32)` at load. **Candidate = `Overlay`** (`SecondaryMap<ParamId, Option<ParamValue>>`), applied at render time, never mutation. `fx::Params` becomes the unbound string form; `ModuleState` becomes a serde projection; `DynPredictor::apply_update(StateUpdate)` survives as the static-lane applicator.
- **One addressing story:** leaf node names are unique program-wide; trace `CompId` interns the same strings; `ParamPath = "<leaf>.<slot>"`. Spans, overlays, optimizers, and serving all resolve through `Program`.
- **Capabilities are declared in the syntax** (WIT model): program `caps` is the ceiling; holes/tools declare subsets; the runtime refuses programs whose caps exceed its grants. Checked at load, enforced by injection (deny-by-default sandbox).
- **Text format:** BAML-style token economy, ~20 keywords, LL(1) after keyword dispatch, full EBNF in §4. Dual frontends (Rust builder / text) construct the same `Program`; `to_ir()` is total because closures are unrepresentable in the builder API (Microsoft Agent Framework rule). The text format is the *only* wire form of a program.
- **Three artifacts:** `qa.dsrs` (program), `qa.state.json` (execution state / checkpoint, Temporal split), `qa.trace.jsonl` (RFC 0001). Cross-referenced by stable xxhash64 hashes; lineage stamped on bake; secrets structurally absent.
- **Compilation = lowering:** interpreter for generation/optimization inner loops; `include_program!` (sqlx/prost precedent) emits the monomorphized static lane for shipping; `dsrs serve` is the interpreter behind typed endpoints projected from `SignatureDef`.

## 1. Value-level signatures (phase-1 prerequisite)

### 1.1 `SignatureDef`

Self-contained, owned, constructible without macros. Lives in `crates/dspy-rs/src/ir/sig.rs`. No `Sym`s inside — a `SignatureDef` must be constructible with zero context (interner coupling would forbid that); the *graph* speaks `Sym`s, signatures speak strings. Field-name lookups at render/parse time are over ≤ dozens of short strings and are not the hot path (prompt rendering and the network are).

```rust

### 1.2 The static lane mapping and the interner story

Today four `Box::leak`'d `TypeId` caches exist (`SignatureSchema::of`, blanket `Schema::output_schema`, `internal_name_for_shape`, plus the per-derive `OnceLock` fast path). The failure mode was never the static lane — leaking once per *compile-time* type is a static allocation in disguise. The failure mode is dynamic loading through the same caches (unbounded leak per load). So:

- **Static lane:** the four caches collapse into **one** `StaticSigCache: TypeId -> &'static SignatureDef` (still deliberately leaked; bounded by the closed set of compiled signature types). `SignatureSchema` becomes a façade over `SignatureDef` in stage IR-1 and is deleted in IR-3 (§7). `Signature::schema()` keeps returning `&'static` — no API break.
- **Dynamic lane:** a loaded `Program` **owns** `sigs: PrimaryMap<SigId, SignatureDef>`, `types: TypeTable`, and `syms: Interner`. Dropped with the program. No global cache is ever touched by loaded IR.

```rust
impl SignatureDef {
    /// Static → value lane. Converts S::schema()'s facet-derived data
    /// (FieldSchema → FieldDef) once per type; cached in StaticSigCache.
    pub fn of<S: Signature>() -> &'static SignatureDef;

    /// Structural equality against a static signature: same field names,
    /// FieldTypes, aliases (instruction text excluded — it's a parameter).
    /// Used by include_program!-emitted binding checks and replay.
    pub fn matches<S: Signature>(&self) -> Result<(), SigMismatch>;
}
```

The `Interner` itself (graph-side symbols — node names, field refs in bindings):

```rust
use cranelift_entity::{PrimaryMap, entity_impl};

#[derive(Clone, Copy, PartialEq, Eq, Hash, Debug)]
pub struct Sym(u32);
entity_impl!(Sym, "sym");

#[derive(Clone, Default)]
pub struct Interner {
    strings: PrimaryMap<Sym, Box<str>>,
    index: hashbrown::HashMap<Box<str>, Sym>,   // the intern index IS the boundary
}
impl Interner {
    pub fn intern(&mut self, s: &str) -> Sym;
    pub fn get(&self, sym: Sym) -> &str;
    pub fn lookup(&self, s: &str) -> Option<Sym>;
}
```

### 1.3 The dynamic type subset

Exactly `FieldType`'s closed set — extend, don't reinvent: `String | Int | Float | Bool | Literal | List | Optional | Map<String,_> | Class | Enum | Union`. `FieldType`, `ClassDef`, `EnumDef`, `FieldDef`(typesys), `EnumValueDef` gain `Serialize/Deserialize` (stage IR-1; purely additive). Everything the derive rejects, the loader rejects with the same wording: data-carrying enums, non-string map keys, `u64/u128/usize/i128`, tuples, bare `serde_json::Value`, fn/trait-object types.

Class/enum definitions referenced by `FieldType::Class(name)`/`Enum(name)` live in the program's type table:

```rust
/// Owned registry of user types reachable from any signature in the program.
/// Deliberate exception to "no string maps at runtime": FieldType references
/// classes by name today (render + coerce read these maps), and re-keying to
/// dense ids would fork FieldType. Lookups happen at load-validation and at
/// per-field render/coerce — measured non-hot. Revisit only with profiler proof.
#[derive(Clone, Debug, Default, Serialize, Deserialize)]
pub struct TypeTable {
    pub classes: IndexMap<String, ClassDef>,
    pub enums: IndexMap<String, EnumDef>,
}
```

### 2.1 Ids and `Program`

```rust

    pub format: u32,             // "dsrs 1" pragma; this RFC = 1

/// LMConfig is already serde with api_key #[serde(skip)] — reused verbatim.

pub struct ModelDef {
    pub name: Box<str>,          // "@fast"

}

#[derive(Clone, Debug)]
pub struct ToolDef {

### 2.2 The `Node` enum

Closed. Nodes form a **tree** (single parent, single use); fan-in/reuse happens through field references, not shared nodes. Leaf nodes (`Predict`, `AgentLoop`, `Hole`) carry a mandatory, **program-unique** name — the trace component name and the `ParamPath` prefix. Containers are anonymous.

```rust
pub enum Node {
    Predict(PredictNode),
    AgentLoop(AgentLoopNode),
    Seq(SeqNode),
    ForkJoin(ForkJoinNode),
    Route(RouteNode),
    Retry(RetryNode),
    Refine(RefineNode),
    Loop(LoopNode),
    Hole(HoleNode),
}

/// One LM call. No tools — tool use is AgentLoop. `cot` in the surface
/// syntax lowers to a Predict over `sig.augmented_with([reasoning])`.
pub struct PredictNode {
    pub name: Sym,
    pub sig: SigId,
    pub instruction: ParamId,        // ParamKind::Instruction
    pub demos: ParamId,              // ParamKind::Demos
    pub model: ParamId,              // ParamKind::ModelRef
    pub binding: Box<[Binding]>,
}

/// The LLM+tool loop as the first-class unit everyone serves.
pub struct AgentLoopNode {
    pub name: Sym,
    pub sig: SigId,
    pub instruction: ParamId,
    pub demos: ParamId,
    pub model: ParamId,
    pub tools: Box<[ToolId]>,
    pub context_policy: ParamId,     // ParamKind::ContextPolicy
    pub stop: StopSpec,
    pub budget: NodeBudget,
    pub binding: Box<[Binding]>,
}

pub struct StopSpec {
    /// Mandatory and bounded — the IR has no unbounded loops, anywhere.
    pub max_turns: std::num::NonZeroU32,
    /// Calling one of these tools ends the loop; its args become the raw
    /// final output (the "submit answer" pattern).
    pub stop_tools: Box<[ToolId]>,
    /// Stop when an assistant turn parses as sig outputs (default true).
    pub until_parse: bool,
}

pub struct NodeBudget {
    pub max_lm_calls: Option<u32>,
    pub max_tokens: Option<u64>,
    pub deadline_ms: Option<u64>,
    pub on_exhausted: BudgetPolicy,
}
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum BudgetPolicy {
    /// RunError::Budget — default.
    Fail,
    /// One forced final round-trip without tools ("wrap up now"), then parse.
    Finalize,
}

pub struct SeqNode {
    pub body: Box<[NodeId]>,
    /// The exported fields of this scope: dst field name -> port.
    pub out: Box<[Binding]>,
}

pub struct ForkJoinNode {
    /// Branches run concurrently; all-success or fail-fast (§3.4).
    pub branches: Box<[NodeId]>,
    pub join: Box<[Binding]>,
}

pub struct RouteNode {
    /// Must resolve to an Enum-typed (or Literal-union) field.
    pub on: PortRef,
    /// (variant name, arm). Arms must export identical field name/type sets;
    /// that set is the RouteNode's output interface.
    pub arms: Box<[(Sym, NodeId)]>,
    pub default: Option<NodeId>,     // required unless arms cover the enum
}

pub struct RetryNode {
    pub child: NodeId,
    pub max_attempts: std::num::NonZeroU32,
    pub backoff_ms: u32,
    /// On Parse failure, append the parse error as a corrective user turn
    /// on the retry (leaf children only; ignored for containers).
    pub feedback: bool,
}

pub struct RefineNode {
    pub child: NodeId,
    /// A Predict or Hole whose sig outputs at least {score: float, feedback: string}.
    pub judge: NodeId,
    pub threshold: f64,
    pub max_rounds: std::num::NonZeroU32,
    /// Child input field that receives judge feedback on re-run.
    pub feedback_field: Sym,
}

pub struct LoopNode {
    pub body: NodeId,
    pub max_iters: std::num::NonZeroU32,
    /// Bool-typed output port of body; loop continues while true.
    /// None = run exactly max_iters.
    pub while_: Option<PortRef>,
    /// Next-iteration inputs from this iteration's outputs (`^name` ports).
    pub carry: Box<[Binding]>,
    pub out: Box<[Binding]>,
}

/// LACUNA-style typed hole: opaque-but-typed sandboxed code. The optimizer
/// sees a signature and a Code gene; the type system sees a normal node.
pub struct HoleNode {
    pub name: Sym,
    pub sig: SigId,
    pub code: ParamId,               // ParamKind::Code
    pub caps: CapSet,                // ⊆ program.caps
    pub binding: Box<[Binding]>,
}
```

### 2.3 Dataflow: field-level

**Decision: field-level wiring.** Value-level (whole-struct) wiring would force a glue hole for every rename/projection — exactly the escape-hatch proliferation that rots closed graphs (§4.1 of the vision). Field-level is also what makes demo harvesting, CoT augmentation, and grammar-constrained generation compose.

```rust
pub struct Binding {
    pub dst: Sym,                    // input field of the owning node / exported name
    pub src: PortRef,
}

pub enum PortRef {
    /// `$.field` — enclosing scope's input (program input at root;
    /// loop body sees carry values here too).
    Input(Sym),
    /// `name.field` — output field of an earlier node in scope.
    Out { node: NodeId, field: Sym },
    /// `^field` — previous iteration's carried value (Loop bodies only).
    Carried(Sym),
    /// JSON literal.
    Lit(serde_json::Value),
}
```

Scoping and validation (all enforced by `Program::validate()` / builder `finish()` / loader — same code path):

1. A node may reference: its scope's inputs, outputs of nodes *earlier* in the enclosing `Seq` chain (including any ancestor's earlier siblings), `Carried` only inside a `Loop` body.
2. Every leaf input field is bound exactly once; every `Out` field exists on the referenced node's interface; bound port type must equal (or coerce per `typesys::coerce` widening: `Int→Float`, `T→Optional<T>`, `T→Union containing T`) the destination `FieldType`.
3. Leaf names unique program-wide. Route arms type-identical. `Route.on` enum-typed with covered variants or a default. All loops bounded by construction (`NonZeroU32`).
4. Node/tool/hole caps ⊆ `program.caps`.
5. Acyclicity is structural: trees + earlier-sibling references cannot cycle.

At the interpreter boundary the value model is `serde_json::Map<String, Value>` per node output (`JsonMap`, as in RFC 0001) — the same model `typesys` renders and coerces today.

### 2.4 Parameters: `ParamSlot`, `ParamPath`, `Overlay`

Every mutable thing is a slot. The serialized program *is* the optimization surface.

```rust
pub struct ParamSlot {
    /// Canonical human/serde form: "<leaf>.<slot>" —
    /// "drafter.instruction", "drafter.demos", "researcher.model",
    /// "researcher.context", "tool.search.desc", "checker.code".
    pub path: Box<str>,
    pub owner: ParamOwner,
    pub kind: ParamKind,
    /// Current value, materialized at build (instruction slots copy the sig
    /// instruction; demos default empty; model slots hold the declared @ref).
    /// Optimizers read this as the incumbent gene.
    pub default: ParamValue,
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum ParamOwner { Node(NodeId), Tool(ToolId) }

#[derive(Clone, Copy, PartialEq, Eq, Debug, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ParamKind { Instruction, Demos, ToolDesc, ModelRef, ContextPolicy, Code }

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(tag = "k", rename_all = "snake_case")]
pub enum ParamValue {
    Instruction { text: String },
    Demos { rows: Vec<DemoRow> },
    ToolDesc { text: String },
    ModelRef { model: ModelId },
    ContextPolicy { policy: ContextPolicy },
    Code { lang: CodeLang, source: String, /// xxhash64 of source
           hash: u64 },
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct DemoRow { pub input: JsonMap, pub output: JsonMap }

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum CodeLang { Js }        // wasm reserved

/// The open-lane optimizable slot (vision §6.6). Minimal v1; additive later.
#[derive(Clone, Debug, Default, PartialEq, Serialize, Deserialize)]
pub struct ContextPolicy {
    pub max_history_turns: Option<u32>,
    pub tool_result_max_bytes: Option<u32>,

    /// Cheatsheet pattern) — reflective optimizers write here.
    pub playbook: Option<String>,

```

`ParamPath` resolution happens **once at load**: the loader builds `HashMap<Box<str>, ParamId>` (serde boundary), everything after speaks ids.

```rust
impl Program {
    pub fn param_id(&self, path: &str) -> Option<ParamId>;
    pub fn param_path(&self, id: ParamId) -> &str;
    /// The optimizer contract, item (1): enumerable typed genes.
    pub fn slots(&self, kind: ParamKind) -> impl Iterator<Item = (ParamId, &ParamSlot)>;
    pub fn slot_of<K: KindTag>(&self, path: &str) -> Option<Slot<K>>;   // kind-checked
}

/// Typed slot handle: optimizer-side mutation mistakes are compile errors.
pub struct Slot<K: KindTag> { pub id: ParamId, _k: std::marker::PhantomData<K> }
pub enum Instruction {}  pub enum Demos {}  pub enum ToolDesc {}
pub enum ModelRefK {}    pub enum ContextK {} pub enum CodeK {}

```

**The candidate type:**

```rust
/// A candidate = dense data overlay over a fixed skeleton. Clone is a vec
/// clone (≈ memcpy for the common instruction-only candidate). Never applied
/// by mutation in the dynamic lane — the interpreter reads through it at
/// render time.
#[derive(Clone)]
pub struct Overlay {
    /// program_hash this overlay was minted against; all apply/serde paths
    /// verify it. Prevents the stale-candidate-on-new-skeleton bug class.
    pub base: u64,
    values: SecondaryMap<ParamId, Option<ParamValue>>,   // default None
}

impl Overlay {
    pub fn new(p: &Program) -> Self;
    /// Kind-checked: setting Demos into an Instruction slot is an error
    /// (or a compile error via the typed variants below).
    pub fn set(&mut self, p: &Program, id: ParamId, v: ParamValue) -> Result<(), OverlayError>;
    pub fn set_instruction(&mut self, s: Slot<Instruction>, text: impl Into<String>);
    pub fn set_demos(&mut self, s: Slot<Demos>, rows: Vec<DemoRow>);
    pub fn set_code(&mut self, s: Slot<CodeK>, source: String);
    pub fn get(&self, id: ParamId) -> Option<&ParamValue>;
    /// Effective value: overlay else slot default.
    pub fn resolve<'a>(&'a self, p: &'a Program, id: ParamId) -> &'a ParamValue;
    /// Stable xxhash64 over (base ++ sorted set entries) — this is
    /// TraceMeta.candidate_hash and the rollout-cache key.
    pub fn hash(&self) -> u64;
    /// Serde boundary: path-keyed JSON ("<path>": ParamValue).
    pub fn to_named(&self, p: &Program) -> std::collections::BTreeMap<String, ParamValue>;
    pub fn from_named(p: &Program, m: std::collections::BTreeMap<String, ParamValue>)
        -> Result<Self, OverlayError>;
}
```

**Composition with today's seams — migration contract:**

- **`fx::Params` becomes the unbound string form of an overlay.** Its `BTreeMap<String, (hash, PredictState)>` is exactly `{path → (Instruction?, Demos?)}` pairs. It gains `Params::bind(&Program) -> Result<Overlay>` and `Params::from_overlay(&Program, &Overlay)`. `fx::with_params` remains for the static lane; the interpreter's equivalent is `with_overlay(Arc<Overlay>, fut)` (same tokio `task_local!` shape). The fx predictor cache keys on the pair-hash exactly as today — unchanged behavior, one representation.
- **`DynPredictor::apply_update(StateUpdate)` survives as the static-lane applicator.** Applying an overlay to a Rust-authored (monomorphized) harness = for each `(ParamId → Instruction/Demos)` pair, build `StateUpdate { instruction, demos }` and funnel through the existing seam — the single place prompt caches invalidate. The dynamic lane never calls it: the interpreter resolves through the overlay at render time and mutates nothing (this is what makes N candidates evaluable concurrently over one `Arc<Program>`).
- **`ModuleState` becomes a serde projection of `Overlay`** (`predictors: BTreeMap<path, PredictState>` ↔ `to_named` restricted to Instruction/Demos kinds). Legacy `.json` files load via a compatibility reader for one release, then die.

### 3.1 Loading and the runtime environment

```rust
pub struct RuntimeEnv {
    /// ModelId -> live LM. Constructed from ModelDef.config + secrets from
    /// the host (env vars / keychain) — secrets never transit the artifact.
    pub models: SecondaryMap<ModelId, Option<std::sync::Arc<crate::LM>>>,
    /// Host tool bindings by name (serde boundary, consulted once at load).
    pub host_tools: std::collections::HashMap<String, std::sync::Arc<dyn rig::tool::ToolDyn>>,
    pub sandbox: std::sync::Arc<dyn dsrs_tools::Executor>,   // QuickJsExecutor in v1
    /// What this host permits. program.caps ⊄ grants ⇒ load refused.
    pub grants: CapSet,
}

pub struct Interpreter {
    program: std::sync::Arc<Program>,
    env: std::sync::Arc<RuntimeEnv>,
}

impl Interpreter {
    /// Load-time checks, in order — nothing lazy, nothing at call time:
    /// 1. Program::validate() (§2.3 rules)
    /// 2. program.caps ⊆ env.grants               (WIT rule: no ambient authority)
    /// 3. every ModelId bindable                   (client constructible)
    /// 4. every ToolKind::Host name bound
    /// 5. every Sandboxed tool + Hole registered through the dsrs-tools
    ///    lifecycle: parse → compile → self-test → register (LATM). A hole
    ///    that doesn't compile fails the LOAD, not the call.
    pub fn load(program: Program, env: RuntimeEnv) -> Result<Self, LoadError>;

    pub async fn run(
        &self,
        input: JsonMap,
        overlay: Option<std::sync::Arc<Overlay>>,
        budget: Budget,
    ) -> Result<JsonMap, RunError>;
}

pub struct Budget {
    pub max_lm_calls: Option<u32>,
    pub max_tokens: Option<u64>,
    pub deadline: Option<std::time::Instant>,
}
```

### 3.2 Per-node evaluation

| Node | Evaluation | Span (RFC 0001) |
|---|---|---|
| `Predict` | resolve bindings → render prompt: instruction = `overlay.resolve(instruction)`, demos likewise, sig fields via existing `ChatAdapter` paths over `SignatureDef`; model = resolved `ModelRef` → `env.models`; call; parse via `typesys::coerce` into output JsonMap | one span, `component` = node name, no events beyond final `Exchange` |
| `AgentLoop` | same prompt seed + tool definitions (descs from ToolDesc slots, overlay-resolved); loop via the existing `LM::call_with_toolset` machinery under a child `BudgetMeter`; stop per `StopSpec`; `ContextPolicy` applied between round-trips (truncation/compaction/playbook) | **one span, N events** (`Exchange`/`ToolRun`) — exactly RFC 0001 §1's attribution unit |
| `Seq` | children in order; each output lands in `frames`; scope output = `out` bindings | none (children emit) |
| `ForkJoin` | branches as tasks in a `tokio::JoinSet`; each branch body runs under its own `capture`-compatible guard (span attribution travels with `SpanGuard`, so interleaving cannot cross-attribute — RFC 0001 §3.1); first error aborts siblings | none |
| `Route` | resolve `on` port → enum string; select arm else `default`; unmatched + no default = `RunError::Route` | none |
| `Retry` | run child; on `Lm`/`Parse`/`Tool` error, backoff and re-run ≤ `max_attempts`; `feedback` appends the parse error as a corrective user turn on leaf children; `Budget`/`CapabilityDenied` are **not** retryable | children emit; each attempt is a fresh span (`seq` increments) |
| `Refine` | run child → run judge with child outputs bound → if `score < threshold` and rounds remain, re-run child with judge `feedback` bound to `feedback_field` | child + judge spans per round |
| `Loop` | ≤ `max_iters`: push carry frame as scope input (`Carried` refs), run body, evaluate `while_` port, rebind carry | body leaves emit; `(component, seq)` disambiguates iterations — this is what RFC 0001's `seq` exists for |
| `Hole` | capability gate (§3.5) → `env.sandbox.execute(ToolInvocation { name, args: input JsonMap })` → result coerced to sig outputs | one span: `model` interns the reserved config `{model: "sandbox:quickjs"}`, `events` = one `ToolRun`, `raw_output` = result JSON, `output` = coerced map. Stays inside the frozen trace format; `for_component(name)` gives Code-gene reflection material for free |

`eval_predict`, abbreviated, showing the span discipline (identical two-phase shape as RFC 0001 §3.1):

```rust
async fn eval_predict(&self, n: &PredictNode, cx: &mut Cx) -> Result<JsonMap, RunError> {
    let input = self.resolve_bindings(&n.binding, cx)?;                  // JsonMap
    let instruction = cx.resolve_text(&self.program, n.instruction);     // overlay-aware
    let demos = cx.resolve_demos(&self.program, n.demos);
    let (prefix, suffix) = render(&self.program.sigs[n.sig], instruction, demos, &input)?;
    let lm = self.model_for(cx, n.model)?;                               // overlay-aware ModelRef

    cx.meter.try_reserve_call().map_err(|_| RunError::budget(n.name))?;
    let guard = crate::trace::begin_span(SpanRequest {
        component: self.program.syms.get(n.name),
        prefix: Some(&prefix), suffix: &suffix,
        input: Some(input.clone()), model: &lm.config,
    });
    let resp = lm.call(chat_of(prefix, suffix)).await;                    // …
    cx.meter.record_usage(&resp.usage);
    let out = coerce_outputs(&self.program.sigs[n.sig], &self.program.types, &resp)?;
    if let Some(g) = guard { g.finish(outcome_of(&resp, &out)); }
    Ok(out)
}
```

### 3.3 One addressing story: CompId/ParamId

- Leaf node names are the shared namespace. A span's `component` string == the leaf name == the `ParamPath` prefix. `Trace::for_component("drafter")` slices the same entity `program.param_id("drafter.instruction")` mutates.
- When a capture scope closes around an interpreter run, `Trace::attach_program(&Program)` fills the additive `param_ids` column RFC 0001 §1 reserved on `Trace::components` (per-trace `CompId` → global `ParamId`s of that component's slots). No format bump; static-lane harnesses just leave the column `None`.
- `TraceMeta.candidate_hash = overlay.hash()`; `TraceMeta.tags["program"] = hex(program_hash)`. The rollout cache keys on `(candidate_hash, example_id)` exactly as the eval engine expects.

### 3.4 Budgets and errors

```rust
pub struct BudgetMeter {
    limits: Budget,
    lm_calls: std::sync::atomic::AtomicU32,
    tokens: std::sync::atomic::AtomicU64,
    parent: Option<std::sync::Arc<BudgetMeter>>,   // AgentLoop chains a child meter
}
impl BudgetMeter {
    /// Check-before-call: calls + deadline are hard-gated pre-call; token
    /// budgets are soft (checked against accumulated usage, since usage is
    /// only known post-hoc). Reservation recurses into parent.
    pub fn try_reserve_call(&self) -> Result<(), Exhausted>;
    pub fn record_usage(&self, u: &crate::LmUsage);
}

#[derive(Debug, thiserror::Error)]
pub enum RunError {
    #[error("lm error at `{at}`: {source}")]        Lm     { at: Box<str>, source: crate::LmError },
    #[error("parse error at `{at}`")]               Parse  { at: Box<str>, raw: String },
    #[error("tool `{tool}` failed at `{at}`")]      Tool   { at: Box<str>, tool: Box<str>, message: String },
    #[error("hole `{at}` failed")]                  Hole   { at: Box<str>, source: dsrs_tools::ExecError },
    #[error("capability `{cap}` denied at `{at}`")] CapabilityDenied { at: Box<str>, cap: Box<str> },
    #[error("budget exhausted at `{at}`")]          Budget { at: Box<str> },
    #[error("route unmatched at `{at}`: `{value}`")]Route  { at: Box<str>, value: String },
    #[error("cancelled")]                           Cancelled,
}
```

Propagation: fail-fast up the tree. `Retry`/`Refine` intercept `Lm | Parse | Tool | Hole`. `ForkJoin` aborts siblings on first error; aborted branches' open spans record `Cancelled` via guard-drop (RFC 0001 §3.1). `BudgetPolicy::Finalize` converts an `AgentLoop` budget hit into one tool-less closing round-trip before parsing.

### 3.5 Capability checking

Three gates, no ambient authority at any point (WIT component model — this precedent set the design: a program that never declares `net` *cannot* be lowered into one that has it):

1. **Build/parse:** node/tool caps ⊆ program `caps` — a validation error, not a warning.
2. **Load:** program `caps` ⊆ `env.grants` — `LoadError::CapsExceedGrants { missing }`.
3. **Execution:** enforcement is *constructive* — the sandbox for a hole/tool is assembled with exactly the `Capability` host functions its declared caps name (dsrs-tools deny-by-default runtime: no fs, no net, no env exists unless injected). There is nothing to check at call time because undeclared authority is unreachable.

## 4. The text format

`.dsrs` files. Design targets, in priority order: token economy (BAML's compact type syntax cut 50–80% of schema tokens — adopted), grammar-constrainable generation, greppable/diffable artifacts.

### 4.1 Keywords

Closed set (23): `dsrs program caps model sig class enum tool lineage main in out predict cot agent hole seq fork join route retry refine loop else js demos`. Plus type primitives `string int float bool map` and sigils `$ @ ^`.

### 4.2 Grammar (EBNF)

Every declaration and expression is keyword-led → LL(1) after one token of lookahead; directly transcribable to GBNF/llguidance for constrained decoding. Whitespace-insensitive; `//` comments; strings are JSON strings; `CODE` is a raw ```` ``` ````-fenced block; `JSONARR` is a raw JSON array.

```ebnf
file        ::= "dsrs" INT program ;
program     ::= "program" IDENT topdecl* main ;
topdecl     ::= capsdecl | modeldecl | sigdecl | classdecl | enumdecl
              | tooldecl | lineage ;

capsdecl    ::= "caps" "{" cap* "}" ;
cap         ::= IDENT ( ":" IDENT )* ;

modeldecl   ::= "model" IDENT "=" STRING opts? ;
opts        ::= "{" opt* "}" ;
opt         ::= IDENT value ;
value       ::= STRING | NUMBER | BOOL | IDENT ;

sigdecl     ::= "sig" IDENT "{" STRING? sigfield+ "}" ;
sigfield    ::= ( "in" | "out" ) IDENT ":" type fieldmeta* ;
fieldmeta   ::= STRING                                  (* doc *)
              | "alias" STRING
              | "check" "(" STRING "," STRING ")"       (* expr, label *)
              | "assert" "(" STRING ")" ;
type        ::= unit ( "|" unit )* ;
unit        ::= prim postfix* ;
prim        ::= "string" | "int" | "float" | "bool"
              | STRING                                  (* literal type *)
              | IDENT                                   (* class/enum ref *)
              | "map" "<" type ">"                      (* string keys implied *)
              | "(" type ")" ;
postfix     ::= "[]" | "?" ;

classdecl   ::= "class" IDENT "{" ( IDENT ":" type STRING? )+ "}" ;
enumdecl    ::= "enum" IDENT "{" ( IDENT STRING? )+ "}" ;

tooldecl    ::= "tool" IDENT STRING ( "caps" "[" cap* "]" )?
                "{" sigfield+ "}" ( "js" CODE )? ;      (* js absent = host tool *)

main        ::= "main" ":" IDENT "=" expr ;

expr        ::= "predict" IDENT modelref? args? nodeopts?
              | "cot"     IDENT modelref? args? nodeopts?
              | "agent"   IDENT modelref? args? agentopts
              | "hole"    IDENT args? "caps" "[" cap* "]" "js" CODE
              | "seq" "{" step+ "}"
              | "fork" "{" ( IDENT "=" expr )+ "}" "join" bindmap
              | "route" port "{" arm+ ( "else" "->" expr )? "}"
              | "retry"  "(" opt* ")" expr
              | "refine" "(" opt* ")" "{" "body" "=" expr "judge" "=" expr "}"
              | "loop"   "(" opt* ")" "{" step+ "}" ;

step        ::= IDENT "=" expr | "out" bindmap ;
arm         ::= IDENT "->" expr ;
args        ::= "(" ( bind ( "," bind )* )? ")" ;
bind        ::= IDENT "=" port ;
bindmap     ::= "{" ( bind ( "," bind )* )? "}" ;
port        ::= "$" "." IDENT                            (* scope input *)
              | IDENT "." IDENT                          (* node output *)
              | "^" IDENT                                (* loop-carried *)
              | literal ;
literal     ::= STRING | NUMBER | BOOL ;
modelref    ::= "@" IDENT ;
nodeopts    ::= "{" ( "instruction" STRING | "demos" JSONARR | opt )* "}" ;
agentopts   ::= "{" ( "tools" "[" IDENT* "]" | "stop_tools" "[" IDENT* "]"
              | "max_turns" INT | "budget" opts
              | "instruction" STRING | "demos" JSONARR | "context" opts | opt )* "}" ;
lineage     ::= "lineage" "{" ( IDENT STRING )* "}" ;
```

Notes: `cot X` lowers to `predict` over `X.augmented_with([reasoning: string])` — pure sugar, printer re-sugars when the augmentation matches. `demos` blocks are raw JSON arrays of `{"input": {...}, "output": {...}}` rows — baked overlays are ordinary diffs to these blocks and to `instruction` strings. The canonical printer is deterministic (`parse(print(p)) == p` is a golden-test invariant).

### 4.3 Worked example — both frontends, one runtime object

Pipeline: CoT draft → tool-using agent loop verifies with search → typed hole filters citations.

**Text form (`qa.dsrs`):**

```

caps { net:search }

model fast = "openai:gpt-4o-mini"        { temperature 0.2 }
model deep = "anthropic:claude-sonnet-4-5" { temperature 0.7 max_tokens 2048 }

  in  question: string
  out answer: string
  out sources: string[]
}

  "Draft a thorough, factual answer."
  in  question: string
  out answer: string
}

sig Research {
  "Verify the draft against sources. Search until every claim is supported; collect URLs."
  in  question: string
  in  draft: string
  out evidence: string[]
}

sig CiteCheck {
  in  draft: string
  in  evidence: string[]
  out answer: string
  out sources: string[]
}

  in  query: string
  out results: string[]
}

main: Main = seq {
  drafter = cot Draft @deep (question = $.question)

  researcher = agent Research @fast (question = $.question, draft = drafter.answer) {
    tools [search]
    max_turns 6

  checker = hole CiteCheck (draft = drafter.answer, evidence = researcher.evidence)
    caps [] js```
      (a) => ({

**Rust builder frontend — constructs the identical `Program` value:**

```rust
use dsrs::ir::{self, FieldType as T, NodeBudget, BudgetPolicy, SignatureDef};

let mut b = ir::ProgramBuilder::new("qa");
b.cap("net:search");
let fast = b.model("fast", LMConfig { model: "openai:gpt-4o-mini".into(),
                                      temperature: 0.2, ..Default::default() });
let deep = b.model("deep", LMConfig { model: "anthropic:claude-sonnet-4-5".into(),
                                      temperature: 0.7, max_tokens: 2048, ..Default::default() });

let main_sig = b.sig(SignatureDef::build("Main")
    .input("question", T::String)
    .output("answer", T::String)
    .output("sources", T::List(Box::new(T::String))).finish()?);
let draft = b.sig_of::<Draft>();          // static-lane #[derive(Signature)] → SignatureDef::of
let research = b.sig_of::<Research>();
let cite = b.sig(SignatureDef::build("CiteCheck")
    .input("draft", T::String)
    .input("evidence", T::List(Box::new(T::String)))
    .output("answer", T::String)
    .output("sources", T::List(Box::new(T::String))).finish()?);

let search = b.host_tool("search", "Web search; returns result snippets with URLs",
                         /*sig*/ b.sig_of::<SearchSig>(), &["net:search"]);

let drafter = b.cot("drafter", draft, deep)          // predict over Draft+reasoning
    .bind("question", ir::input("question"));
let researcher = b.agent("researcher", research, fast)
    .bind("question", ir::input("question"))
    .bind("draft", ir::out(drafter, "answer"))
    .tools([search])
    .max_turns(6)
    .budget(NodeBudget { max_tokens: Some(40_000),
                         on_exhausted: BudgetPolicy::Finalize, ..Default::default() });
let checker = b.hole("checker", cite, JS_CITE_FILTER, &[])
    .bind("draft", ir::out(drafter, "answer"))
    .bind("evidence", ir::out(researcher, "evidence"));

let program: ir::Program = b.main(main_sig, [drafter, researcher, checker])
    .out("answer",  ir::out(checker, "answer"))
    .out("sources", ir::out(checker, "sources"))
    .finish()?;                                       // to_ir(): total (§4.4)

assert_eq!(program.to_text(), include_str!("qa.dsrs"));   // canonical print == source
```

### 4.4 `to_ir()` totality rule

The builder and the parser construct the same in-memory `Program` (Microsoft Agent Framework's dual-frontend rule — the one that prevents the cloudpickle trap). Totality is achieved **by construction**: the builder API has no method that accepts a closure, a `dyn Tool` without a `ToolDef`, an arbitrary `Module`, or an unbounded loop. There is no lossy-export path because the lossy inputs are unrepresentable.

| Wanted | You must write | Rejected outright (no API) |
|---|---|---|
| arbitrary compute | `hole(name, sig, js, caps)` — explicit, typed, sandboxed | Rust closure / `Map` / `AndThen` |
| host-side native code | `host_tool(name, desc, sig, caps)` — declared extern, bound at load | anonymous `Arc<dyn ToolDyn>` |
| unbounded iteration | — | `loop` without `max_iters` (`NonZeroU32` by type) |
| live LM handle | `model(name, LMConfig)` → `@ref` | embedding an `LM` client |

`finish()` returns `Err` (never panics) on: dangling `PortRef`, binding type mismatch, duplicate leaf names, caps exceeding the program ceiling, non-exhaustive `route` without `else`, hole source that fails parse-time syntax check.

## 5. Artifacts

Three files, three jobs (Temporal's program/event-log split, extended by RFC 0001):

| File | Content | Wire form | Mutability |
|---|---|---|---|
| `qa.dsrs` | **Program**: structure + types + sigs + param defaults (+ baked overlay + lineage) | text format §4 — the *only* program serialization | written by humans, LLMs, and `bake` |
| `qa.state.json` | **Execution state**: one in-flight run — checkpoint/resume/interrupt | JSON | written by the interpreter |
| `qa.trace.jsonl` | **Trace**: one completed/streaming rollout | RFC 0001 JSONL | append-only |

```rust
#[derive(Serialize, Deserialize)]
pub struct ExecState {
    pub v: u32,                       // this RFC: 1
    pub program_hash: u64,
    pub overlay_hash: Option<u64>,
    /// Completed node outputs (NodeId.index → JsonMap) + cursor stack
    /// (node, child-index/iteration). Resume = restore frames, continue from
    /// cursor — no LM call replays. The trace prefix is kept alongside for
    /// audit and for RFC 0001 §4d strict verification when wanted.
    pub frames: Vec<(u32, JsonMap)>,
    pub cursor: Vec<(u32, u32)>,
    pub trace: Option<crate::trace::Trace>,   // single-doc form, RFC 0001 §5.1
    /// Human-in-the-loop hook (vision §6.2): a pending interrupt names the
    /// node and payload awaiting approval. Full design deferred; field reserved.
    pub pending: Option<PendingInterrupt>,
}

#[derive(Serialize, Deserialize)]
pub struct PendingInterrupt { pub node: u32, pub reason: String, pub payload: JsonMap }
```

**Relationships.** One hash function everywhere: stable **xxhash64** (`twox-hash`), the same choice RFC 0001 Q4 recommends for `request_hash` — one hasher, four callers (request, overlay, program, code). `overlay.base` and `ExecState.program_hash` reference `program_hash`; `TraceMeta.candidate_hash` = `overlay.hash()`; `TraceMeta.tags["program"]` = program hash. Any consumer can join the three files without parsing program text.

**Overlay lifecycle.** During optimization, candidates are transient `*.ovl.json` (path-keyed `to_named` form). Promotion **bakes**: `Program::bake(&Overlay) -> Program` folds values into slot defaults, rewrites the text artifact (instruction strings, demos blocks, code fences change — the GEPA diff is a *text diff*), and stamps lineage. Serving loads exactly one file.

**Semver.** The `dsrs 1` pragma is the format major. Parsers reject a higher major. Within a major, evolution is additive-keyword-only (new `opt` keys inside existing `{}` blocks, new `fieldmeta` forms); parsers reject unknown *top-level* keywords — text formats cannot skip-unknown safely, so anything structural bumps the major. `ExecState.v` and the trace `h.v` version independently.

**Secrets.** `LMConfig.api_key` is `#[serde(skip)]` (already true) — model entries in the artifact carry provider/URL/sampling only, `base_url` reduced to origin at print time (RFC 0001 §5.3 rule, same code). Capability *grants* are host-runtime state, never serialized. Hole/tool source is content — the LATM register step runs the self-test in the deny-by-default sandbox, so a malicious artifact can at worst call the capabilities the host granted. No code-executing deserialization exists: parsing constructs data; execution requires `Interpreter::load` + explicit grants.

## 6. Compilation

### 6.1 `include_program!` (plan, not full design)

The sqlx/prost precedent: validate at build time, emit monomorphized code, ship zero-cost.

```rust
dsrs::include_program!("programs/qa.dsrs");   // expands in-place to a `qa` module
let out = qa::call(qa::MainInput { question }, &qa::Bindings { search: my_search_tool }).await?;
```

Plan:

1. **Parse + validate** the artifact at macro expansion (§2.3 rules + cap consistency). Emit `const _: &[u8] = include_bytes!(…)` so rustc tracks the file for rebuilds (the sqlx trick; `proc_macro::tracked_path` when stable).
2. **Emit signatures** through the same generation path as `#[derive(Signature)]` — refactor `dsrs-macros::generate_signature_code` to take a macro-independent spec struct so derive and `include_program!` share one emitter. Each `SignatureDef` becomes a real signature type; `SignatureDef::matches::<S>()` asserts the round-trip in a generated `#[cfg(test)]`.
3. **Emit the graph as straight-line code**: `Seq` → sequential `.await`s; `Route` → `match` over the generated enum; `Retry`/`Refine`/`Loop` → `for` loops with the literal bounds; `Predict` leaves → `static`-configured `Predict<SigN>` (baked instruction/demos via the normal builder); `AgentLoop` → `Predict` with tools + `ToolLoopMode::Auto` + budget wrapper; `Hole` → embedded source registered once in a `LazyLock<QuickJsExecutor>` (self-test at first use).
4. **Extern bindings** surface as a generated `Bindings` struct with one typed field per `Host` tool — the host cannot forget to supply one (compile error), the WIT-import analogy.
5. Capability ceiling embedded as a `const CAPS: &[&str]`; the serving/host layer still gate-checks grants at startup — build-time validation covers internal consistency only.

Lifecycle (vision §5.2): LLM generates IR → optimizer evolves it through the *interpreter* (no rustc in the loop) → winning artifact checked in → `include_program!` produces the shipping build.

### 6.2 `dsrs serve program.dsrs` (sketch)

```
dsrs serve qa.dsrs --allow net:search --port 8080
```

- Startup: parse → `Interpreter::load` with grants from `--allow` flags (refuse if `caps ⊄ grants`, printing the missing set), models bound from env-var secrets, holes registered (compile + self-test) — fail fast, before binding the port.
- Endpoints, projected from `SignatureDef` (the Wassette pattern — signature → JSON Schema):
  - `POST /v1/call` — body validated against the program input sig (400 with per-field errors from `typesys::coerce`); response = output JsonMap + usage summary. `?trace=true` adds a `trace_id`.
  - `GET /v1/schema` — OpenAPI document derived from input/output `SignatureDef` + `TypeTable`.
  - `GET /v1/traces/{id}` — recent traces (ring buffer / sink-configurable); OTel batch export per RFC 0001 §4g.
  - `GET /healthz`, `GET /metrics` — token/cost counters from `BudgetMeter` aggregation.
- Candidate serving hook (vision §7.4 trust machinery): registered overlays addressable via `X-Dsrs-Candidate: <overlay-hash>`; the canary router splits traffic incumbent-vs-candidate and tags traces accordingly. Auto-rollback logic is out of scope here.
- Streaming: reserved; lands with `SpanEvent::Chunk` (RFC 0001 §6) as SSE. No IR change required (Q3, §8).

## 7. Migration

### 7.1 What becomes what

| Today | Becomes |
|---|---|
| `SignatureSchema` + 4 leaked `TypeId` caches | `SignatureDef` + one `StaticSigCache` (static lane); program-owned arenas (dynamic lane). `SignatureSchema` = façade in IR-1, deleted in IR-5 |

| `ModuleState` | path-keyed serde projection of `Overlay`; legacy reader one release |
| `Predict<S>` | unchanged as the static leaf; render/parse internals refactored to functions over `&SignatureDef` shared with the interpreter |
| `Predict` with tools / `LM::call_with_toolset` | the `AgentLoop` executor (same loop code); `to_ir` maps tool-bearing Predicts to `AgentLoop` |
| `ChainOfThought<S>` = `Predict<Augmented<S, Reasoning>>` | `cot` sugar ↔ `SignatureDef::augmented_with` — same lowering, two lanes |

| `Module`/`ModuleExt` closure combinators | deleted from the authoring path (unrepresentable per §4.4); `fx` + builder are canonical |

| `dsrs-tools` `Executor`/`ToolSource`/`Capability` | consumed as-is by `Hole`/`ToolKind::Sandboxed`; no changes needed beyond a `register_program` batch helper |

### 7.2 PR-shaped stages

Trace PRs 1–5 are RFC 0001 §7.2. IR stages:

1. **IR-1 `sigdef`** *(phase 1; no deps)* — `SignatureDef`/`FieldDef`/builder; serde on `FieldType` & co.; `SignatureDef::of::<S>()` + `StaticSigCache` collapsing the four caches; `SignatureSchema` reimplemented as a façade delegating to `SignatureDef`. Behavior-neutral; golden tests: derive-built == builder-built for every signature in the test suite.
2. **IR-2 `params`** *(needs IR-1; pairs with trace PR-1)* — `ParamSlot`/`ParamPath`/`ParamId`/`ParamValue`/`Overlay` (+ `cranelift-entity`, `twox-hash`); `fx::Params::bind/from_overlay`; `ModuleState` ↔ `Overlay` projection; one xxhash64 helper adopted by `LM::cache_key_for` (RFC 0001 Q4, done once here).
3. **IR-3 `graph`** *(needs IR-1/2, trace PR-1..3)* — `Program`/`Node`/`Binding`/`validate()`; interpreter for `Predict/Seq/ForkJoin/Route/Retry/Loop`; `with_overlay` scope; span emission + `Trace::attach_program`. Ships behind `ir` feature flag until IR-5.
4. **IR-4 `agent+hole`** *(needs IR-3, dsrs-tools)* — `AgentLoopNode` executor over `call_with_toolset` + `BudgetMeter` + `ContextPolicy`; `HoleNode` + `ToolKind::Sandboxed` through the LATM lifecycle; capability gates; `Refine`.
5. **IR-5 `text`** *(needs IR-3; parallel with IR-4)* — parser + canonical printer + `ProgramBuilder::finish` totality errors; round-trip golden tests (`parse∘print` = id; builder == parsed); delete `SignatureSchema` façade, `Module`/`ModuleExt` closure combinators, facet walker (derive-emitted enumeration lands here).
6. **IR-6 `bake+state`** *(needs IR-4/5)* — `Program::bake`, lineage stamping, `ExecState` checkpoint/resume, overlay `.ovl.json` form; optimizers (Bootstrap/GEPA on the eval engine) switch their candidate type to `Overlay`.
7. **IR-7 `compile+serve`** *(needs IR-5/6)* — `include_program!` per §6.1; `dsrs serve` per §6.2.

Deleted overall (beyond RFC 0001's list): the four-cache leak pattern for dynamic types, `visit_named_predictors_mut` + `PredictAccessorFns` + the raw-pointer accessor hack, closure combinators, `ModuleState` as a primary format, tool-bearing-`Predict` as a distinct execution path.

## 8. Open questions

1. **Entity plumbing: `cranelift-entity` dependency or ~150 in-house lines?** — *Recommended: depend on `cranelift-entity`.* Zero transitive deps, stable for a decade, exactly `PrimaryMap`/`SecondaryMap`/`entity_impl!`. Write it ourselves only if a future `no_std`/wasm build of the core demands it.
2. **Interpreter value model: `serde_json::Value` frames or an arena'd internal value?** — *Recommended: `serde_json::Value` in v1.* It is already the render/coerce/trace model; the LM call dominates latency by 4–6 orders of magnitude. Revisit only if `benchmarks/` (97-perf-microbench) shows frame handling on a profile under heavy `ForkJoin` fan-out.
3. **Does a `Predict` node emit a value or a stream?** — *Recommended: value, frozen for IR v1* (consistent with RFC 0001 §6). Streaming is a serving-host concern surfaced via `SpanEvent::Chunk`/SSE; BAML-style typed partials would arrive as an additive node *attribute* (`stream true` in `nodeopts`) plus a derived partial-output signature — additive under §5's semver rules, no node-enum change.
4. **Demos inline in the artifact or a sidecar file?** — *Recommended: inline JSON blocks.* One self-contained servable file beats prettiness; demo-heavy programs are the artifact's payload, not an accident (RFC 0001 made the same call for prefixes). If artifacts exceed ~1 MB in practice, add an additive `demos file "qa.demos.json"` form within format major 1.
5. **`Route` discriminants beyond enums?** — *Recommended: enums + literal-string unions only, v1.* Arbitrary predicates are computation and belong in a `Hole` that outputs an enum — keeping `Route` decidable is what keeps the graph statically checkable and the grammar small (the AFlow lesson again). Numeric-range arms can be added as an additive `arm` form later if real programs demand them.
